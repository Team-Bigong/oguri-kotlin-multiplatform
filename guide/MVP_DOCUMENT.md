# **1️⃣ 스플래시**

```
🦆 오구리

연차를 전략적으로 쓰면
여행이 달라집니다.

[ 시작하기 ]
```

- 캐릭터 강조
- 여행 느낌 배경
- 광고 없음

---

# **2️⃣ 로그인 화면**

```
3초 만에 전략 확인하기

[ 카카오로 시작하기 ]
[ Apple로 시작하기 ] (iOS)

────────────
[ 게스트로 둘러보기 ]
```

- 게스트는 기능 제한 없음 (Pro 제외)

---

# **3️⃣ 온보딩 화면**

```
나는 누구인가요?

[ 직장인 ]
[ 학생 ]

────────────

남은 연차는?

[ - ] 15일 [ + ]

근무 형태

[ 주 5일 ]
[ 주 6일 ]

────────────
[ 전략 계산하기 ]
```

- 입력 부담 최소화
- 계산 즉시 홈으로 이동

---

# **4️⃣ 홈 (핵심 화면)**

### **구조: “최고 전략 1개 강조”**

```
🦆 오구리

🔥 지금 가장 좋은 전략

10월 6일 ~ 10월 12일
연차 2일 → 7일 확보

[ 이 전략 자세히 보기 ]

────────────

📊 올해 효율 TOP 3

1위 10월 (7일)
2위 9월 (8일)
3위 5월 (4일)

────────────

✈️ 추천 여행지
오사카 · 다낭 · 제주

────────────
[ 배너 광고 영역 ]
```

### **홈 역할**

- 결론 제시
- 상세로 유도
- Pro 직접 강요하지 않음

```
📅 10월 전략

10/6 (월)
10/7 (화)

총 확보:
🔥 7일

[ 미니 달력 보기 ]

────────────

✈️ 추천 여행지
이탈리아
방콕
바르셀로나

────────────

[ Pro로 PDF 저장하기 ]

────────────

```

### **정책**

- 광고는 하단 1개만
- 스크롤 중간 광고 없음

# **6️⃣ 전략 캘린더 화면**

# **8️⃣ 건의하기 → 이메일 연결**

### **1단계: 문의 유형 선택**

```
어떤 문의인가요?

[ 기능 제안 ]
[ 오류 신고 ]
[ 기타 문의 ]
```

### **2단계: 메일 앱 실행**

자동 입력:

제목:

```
[오구리] 기능 제안 문의
```

본문:

```
■ 문의 유형:
기능 제안

■ 내용:

-------------------------
앱 버전: 1.0.0
OS:
기기 모델:
```

# **📢 광고 정책 (확정)**

- 홈 / 상세 / 캘린더 하단 배너 1개
- 화면 높이 10~12% 이하
- 콘텐츠와 Divider로 분리
- 스플래시 / 로그인 / 온보딩 / 마이에는 광고 없음
